# Security FAQ

Acme Payments is certified as a PCI DSS Level 1 Service Provider, which is the highest level of certification in the payments industry. All API traffic must use TLS 1.2 or higher. Card numbers are encrypted at rest with AES-256.

Two-factor authentication is required for every dashboard user with the Administrator role. Acme runs an external security audit every year and a public bug bounty program.

If you suspect that a key is compromised, roll the key immediately and contact support.
