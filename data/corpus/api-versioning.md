# API versioning

Acme uses dated API versions, such as 2024-06-01. Your account is pinned to the API version that was current when you made your first request.

You can override the version for a single request with the Acme-Version header. Acme supports each API version for at least 24 months after a newer version is released.

Breaking changes only ship in new API versions. You can upgrade the default version of your account from the Developers page in the dashboard.
